# .ipbar

локальный IPv4 прямо в строке меню macOS. SwiftUI, AppKit и публичные сетевые API Apple. без внешних сервисов и сторонних библиотек.

macOS 14+, Apple Silicon и Intel.

## разработка

открой `IPBar.xcodeproj`, выбери схему `IPBar` и запусти приложение. параметры сети и выбор интерфейса отделены от представлений; сетевые данные остаются на Mac.
